## Built With

- **React** – Component-based UI development
- **Vite** – Fast frontend tooling for development and build
- **Tailwind CSS** – Utility-first CSS framework for rapid UI styling
- **CSS** – For additional custom styling
- **FontAwesome** – Icon library used throughout the site

## Features

- **Windows 7-inspired interface** - Explorer-style navigation, taskbar, desktop wallpaper, and familiar system UI elements
- **About Me** – Personal introduction and background
- **Skills** – Overview of my technical skills and technologies
- **Projects** – Selected projects with descriptions and links
- **Experience** – Work experience and relevant background
- **Contact** – Email, GitHub, LinkedIn and location information
- **Responsive layout** - Adapted for desktop and mobile screens
- **Custom Windows cursors** - Pointer, text and other cursor states styled to match the interface
- **Windows-style interactions** - Tooltips, navigation feedback
- **SEO and social metadata** - Search-engine and social-sharing metadata for the portfolio

## Design

I chose Windows 7 as the design inspiration because I like its visual style and wanted to create something distinctive.
